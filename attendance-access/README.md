# نظام الحضور والانصراف والأجور الإضافية — Microsoft Access

برنامج متكامل على **Microsoft Access** لتسجيل حضور وانصراف الموظفين، وحساب التأخير والانصراف المبكر والغياب والإجازات، والساعات الإضافية (نهاري / ليلي / راحات وعطلات)، وبدل الغداء والعشاء، والأجور الأساسية والإضافية وصافي المستحق.
كل القواعد قابلة للتعديل من داخل البرنامج، ولا يوجد أي رقم ثابت داخل الحسابات.

---

## 1) التشغيل (دقيقتان)

| الخطوة | الإجراء |
|---|---|
| 1 | انسخ الملف `Build_Attendance_System.vbs` إلى أي مجلد على جهاز Windows عليه **Access 2010 أو أحدث** (أو Microsoft 365). |
| 2 | اضغط عليه مرتين ← وافق على الرسالة ← انتظر رسالة «تم بناء البرنامج بنجاح». |
| 3 | سيُنشأ الملف `Attendance_System.accdb` في نفس المجلد ويُفتح تلقائياً. |
| 4 | اضغط **تمكين المحتوى / Enable Content** في الشريط الأصفر (مرة واحدة)، ثم أغلق الملف وافتحه. ستظهر الشاشة الرئيسية تلقائياً. |

> لماذا سكربت بناء وليس ملف `.accdb` جاهزاً؟ لأن ملفات Access لا يمكن إنشاؤها بنماذجها وتقاريرها إلا من داخل Access نفسه. السكربت يبني كل شيء (جداول، علاقات، استعلامات، نماذج، تقارير، بيانات تجريبية) في ثوانٍ، ويمكن إعادة تشغيله في أي وقت للحصول على نسخة نظيفة.
> إذا ظهرت تحذيرات، سيُنشأ ملف `build_log.txt` بجوار السكربت يوضح الخطوة التي لم تكتمل.

## 2) مكونات البرنامج

### الجداول (Tables)

| الجدول | المحتوى |
|---|---|
| `tblSettings` | الإعدادات العامة وقواعد الحساب (سجل واحد) |
| `tblShifts` | الورديات: بداية/نهاية الدوام + توقيت استحقاق بدل الغداء والعشاء لكل وردية |
| `tblDepartments` | الإدارات |
| `tblEmployees` | الموظفون: الكود، الإدارة، الوردية، الأجر الأساسي، رصيد الاعتيادي |
| `tblAttendance` | حركات الحضور والانصراف (سجل واحد لكل موظف في اليوم — فهرس فريد) |
| `tblLeaves` | الإجازات والمأموريات (من تاريخ – إلى تاريخ) |
| `tblLeaveTypes` | أنواع الإجازات: مدفوعة/غير مدفوعة + الرصيد السنوي |
| `tblHolidays` | العطلات الرسمية |
| `tblCalendar` | تقويم الأيام (يُستخدم لاستنتاج الغياب تلقائياً وحساب أيام الإجازات الفعلية) |

العلاقات مفعّلة بتكامل مرجعي (Referential Integrity)، وتوجد قواعد تحقق (مثل: تاريخ نهاية الإجازة ≥ تاريخ البداية).

### الشاشة الرئيسية `frmMain`
- **فلاتر:** من تاريخ / إلى تاريخ / موظف / إدارة (تطبق على كل التقارير). الافتراضي: الشهر السابق.
- **10 أزرار تقارير** + **12 زر إدخال وإعدادات**: الحضور، الإجازات، الموظفون، الإعدادات، الورديات، الإدارات، أنواع الإجازات، العطلات، عرض الحسابات اليومية، إضافة سنة للتقويم، تحديث، خروج.

## 3) الإعدادات القابلة للتعديل

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| بداية / نهاية الدوام (لكل وردية) | 09:00–17:00 و 14:00–22:00 | ساعات العمل الأساسية؛ تدعم الورديات التي تعبر منتصف الليل |
| سماحية التأخير | 15 دقيقة | التأخير ≤ السماحية لا يُحتسب |
| بدء الإضافي بعد نهاية الوردية | 30 دقيقة | **توقيت بداية حساب الأجر الإضافي** (مثلاً 17:30) |
| الحد الأدنى للإضافي | 30 دقيقة | أقل من ذلك لا يُحتسب |
| بداية الإضافي الليلي | 19:00 | ما بعده يُحسب بالمعامل الليلي |
| معامل الإضافي النهاري / الليلي | 1.35 / 1.70 | قيم الأجر الإضافي |
| معامل العمل في الراحة/العطلة | 2.00 | لكل ساعات العمل في يوم الراحة أو العطلة الرسمية |
| بدل الغداء / العشاء — القيمة | 50 / 75 | قيمة البدل |
| بدل الغداء / العشاء — التوقيت (لكل وردية) | بعد 18:00 / بعد 21:00 | **توقيت استحقاق البدل**: إذا كان الانصراف بعد هذا الوقت وهناك عمل إضافي |
| أيام الشهر لحساب الأجر اليومي | 30 | الأجر اليومي = الأساسي ÷ 30 |
| يوما الراحة الأسبوعية | الجمعة والسبت | قابلة للتغيير لأي يومين |
| أيام الخصم عن كل يوم غياب | 1 | يمكن جعلها 2 كجزاء |
| تفعيل خصم التأخير والانصراف المبكر | غير مفعّل | عند التفعيل: الخصم = دقائق التأخير × أجر الدقيقة |

> النسب الافتراضية (35% نهاري، 70% ليلي، ضعف الأجر في الراحات) مأخوذة كمرجع من قانون العمل المصري 12/2003. **راجعها مع القانون الساري ولائحة الشركة** وعدّلها من شاشة الإعدادات.

## 4) منطق الحساب (محرك الاستعلامات)

السلسلة: `qryAtt_Base → qryAtt_Calc1 → qryAtt_Calc2 → qryAtt_Calc3 → qryAttCalc`

| البند | المعادلة |
|---|---|
| أجر الساعة | الأجر الأساسي ÷ أيام الشهر ÷ ساعات الوردية |
| ساعات العمل | الانصراف − الحضور (يعالج الانصراف بعد منتصف الليل) |
| التأخير | الحضور − بداية الدوام (إذا تجاوز السماحية) |
| الانصراف المبكر | نهاية الدوام − الانصراف |
| الإضافي الكلي | الانصراف − (نهاية الدوام + دقائق بدء الإضافي)، بشرط ≥ الحد الأدنى |
| الإضافي الليلي | الجزء من الإضافي الواقع بعد «بداية الإضافي الليلي» |
| الإضافي النهاري | الإضافي الكلي − الليلي |
| العمل في الراحة/العطلة | كل ساعات اليوم إضافي بمعامل الراحات |
| قيمة الإضافي | أجر الساعة × (نهاري × 1.35 + ليلي × 1.70 + راحات × 2) |
| بدل الغداء/العشاء | يُستحق إذا وُجد إضافي **و** كان الانصراف بعد توقيت البدل للوردية |
| الغياب | **يُستنتج تلقائياً**: يوم عمل (ليس راحة ولا عطلة) بلا حضور ولا إجازة ولا مأمورية |
| أيام الإجازة | تُحسب أيام العمل الفعلية فقط (تُستبعد الراحات والعطلات داخل فترة الإجازة) |
| صافي المستحق | الأساسي + الإضافي + البدلات − (خصم الغياب + خصم بدون أجر + خصم التأخير) |

## 7) الاستخدام اليومي

1. **تسجيل الحضور:** شاشة «تسجيل الحضور والانصراف» (Datasheet سريع): اختر الموظف، التاريخ (افتراضياً اليوم)، اكتب الوقت مثل `08:55` و `17:30`. يمكن لصق بيانات جهاز البصمة مباشرة من Excel بنفس ترتيب الأعمدة.
2. **الإجازات:** شاشة «تسجيل الإجازات والمأموريات» (من – إلى).
3. **نهاية الشهر:** حدد الفترة في الشاشة الرئيسية ← افتح تقرير 08 ثم 09.
4. **مراجعة أي يوم:** «عرض الحسابات اليومية» يوضح كل أرقام الحساب لكل حركة.
5. **التقويم:** مُجهَّز من بداية العام السابق حتى نهاية بعد عامين؛ زر «إضافة سنة للتقويم» يمده سنة إضافية.

### نصائح للأداء والتوسع
- البيانات مفهرسة على (الموظف + التاريخ) والتاريخ، والحسابات كلها SQL بدون دوال VBA ← سريعة حتى عشرات الآلاف من الحركات.
- لتعدد المستخدمين: **Database Tools ← Move Data ← Access Database** لفصل الجداول (Back-end) على السيرفر وتوزيع الواجهة (Front-end) على الأجهزة.
- لعمل لوحات متابعة في **Power BI / Excel** اربط الاستعلام `qryAttCalc` (كل الحسابات اليومية بدون فلاتر) والجداول `tblEmployees` و `tblLeaves` عبر Get Data ← Access Database. (استعلامات التقارير `qryR..` تعتمد على فلاتر الشاشة الرئيسية فلا تُستخدم خارج Access.)
